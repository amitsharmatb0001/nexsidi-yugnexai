# Mobile layout

- Check every page at 375 px wide: no horizontal scrolling, no clipped
  text, nothing hidden behind other elements.
- Grids collapse to one column under 640 px; key figure cards stack.
- Tables become cards on phones (see tables-search-filters).
- Navigation collapses into a menu button; Sign Out stays reachable.
- Tap targets at least 44 px high; inputs at least 16 px font so phones do
  not zoom in.
- Long values (emails, GSTINs, invoice numbers) wrap or truncate with the
  full value available.
